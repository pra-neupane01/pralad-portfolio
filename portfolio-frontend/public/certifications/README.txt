Place your 4 certificate JPG images in this directory (public/certifications/).

Recommended file names:
- cert1.jpg
- cert2.jpg
- cert3.jpg
- cert4.jpg

Or name them according to your certificate title, for example:
- aws-cloud-practitioner.jpg
- fullstack-web-dev.jpg
- react-developer.jpg
- python-masterclass.jpg

Once placed here, reference them in `src/data/certifications.js` using:
image: '/certifications/your-image-name.jpg'
